# RaceDay

## Overview
RaceDay is a race event management system.

## Key Roles

### Organiser
The Organiser is responsible for setting up and managing race events, creating participant lists, and monitoring race progress.

### Participant
A Participant is an individual registered to compete in a RaceDay event.

## Features
- Event organization and management
- Participant registration and tracking
- Race timing and results
